# Step 3 — Take a guided tour

!!! abstract "Goal"
    See the application fully populated before building anything yourself.

## Background

Four demo sites ship with the application, each with a scripted walkthrough that narrates
a real finding in the data. They are the fastest way to see what the tool is for.

All four are **read-only**. They never offer edit, clone or delete, so you cannot damage
them — which makes them a good place to experiment.

## Steps

1. From the landing page, choose one of the four audience cards.
2. The tour loads its demo site and steps through a sequence of findings.
3. Use **Next** to advance, or close the tour at any point.

### The four tours

| Card | Demo site | Focus |
|---|---|---|
| Explore Conservation Futures | Munywana | Woody biomass, tree cover, herbivore grazing pressure |
| Explore Shared Landscapes | Viphya | Miombo woodland restoration and tree-cover trade-offs |
| Explore Policy Impacts | Shai Hills | Forest versus open-savanna restoration, fire and ecosystem processes |
| Explore Future Possibilities | Africa | Continent-scale herbivore biomass loss, methane, fire and carbon trade-offs |

Each tour resets its site's target values when it starts, so a previous run never affects
the next one.

!!! note "Browser users"
    If you are using the browser version rather than the desktop application and it
    becomes slow or stops saving, see the
    [FAQ note on storage](../faq.md). Running a tour is currently enough to exhaust the
    browser's storage allowance on a fresh profile. The desktop application is unaffected.

!!! success "What you achieved"
    - You have seen the application working on real data
    - You know the four demo sites and what each illustrates
    - You know demo sites are read-only and safe to explore
