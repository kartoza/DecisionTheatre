# Step 7 — Identify a catchment

!!! abstract "Goal"
    Inspect the numbers behind a single catchment.

## Background

Colour tells you the shape of a pattern; it does not tell you a value. Identify mode is
how you get from *this area looks high* to *this catchment is 412 g/m²*.

It is available in single-pane view only — in a grid of panes a click would be ambiguous.

## Steps

1. Switch to single-pane view if you are in grid view.
2. Turn on **identify mode** with the info icon on the map toolbar.
3. Click any catchment. A popup opens showing every attribute for that catchment across
   both compared scenarios, plus its departure from the ecological reference.
4. Click the site boundary line itself instead to see site-wide indicator values.
5. Close the popup with its **×** button.

!!! note "Reading the popup"
    Each row shows the value under both scenarios side by side, with a bar whose length is
    proportional to the larger of the two — so you can see the direction and rough size of
    a difference without reading the numbers.

!!! success "What you achieved"
    - You can inspect a single catchment's values
    - You can read site-wide values by clicking the boundary
    - You know identify mode is single-pane only
